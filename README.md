Лабораторная №3. Вёрстка макета с помощью Flexbox и Grid
  Цель: Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также
принципы адаптивной вёрстки.
  Задание:
Дополнить макет страницы:
* Flexbox: навигационное меню (горизонтальное, адаптивное) и карточки (3–4 шт.) в
ряд.
* Grid: галерея/дашборд (2–3 колонки, 2–3 строки).
* Медиа-запросы для планшетов и мобильных; отсутствие горизонтальной прокрутки.
* Контрастность ≥ 4.5:1; семантически верные теги для карточек.

Вариант 13. Тема «Волонтёр и социальный активист» (акции и роли) Flex-карточки:
«Текущие акции» (название, дата, роль волонтёра). Grid-сетка: «Роли в команде» (роль,
описание, иконка – 3 блока). Адаптивность: карточки – 1/2/3; Grid – 1/2/3. В семантике –
<nav> для навигации по ролям (если добавите ссылки).
